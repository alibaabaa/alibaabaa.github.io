Type roles

Three, and only three. A fourth role is usually a sign that a section is doing too much.

Display serif. Section-opening statements.

Body sans. Running prose, held to a 56 character measure.

Micro label. Eyebrows, credentials, jump links.

<p class="lede">…</p>             .lede--tight  .lede--lg
<div class="prose"><p>…</p></div>  .prose--narrow
<p class="label">…</p>

Eyebrow

Accent rule above a micro label. Opens a section, or a page with the --lead modifier.

Point of view

<p class="eyebrow label">Point of view</p>

Rule list

A set of items, not a sequence. Unnumbered on purpose.

  • Product security operating model
  • Threat modelling and secure development practice
<ul class="rule-list">
  <li class="rule-list__item"><span class="dot" aria-hidden="true"></span><span>…</span></li>
</ul>

Article card

The whole card is the link. Three per row, collapsing to one below 880px.

The headline of the piece, set in the display serif

One or two sentences saying what the reader gets from it.

A second piece

Hover either card to see the accent rule draw across the top edge.

A third piece

Two or three cards per row read best. Four crowds the measure.

 
<div class="article-grid">
  <a class="article-card" href="…">
    <h3 class="article-card__title">…</h3>
    <p class="article-card__standfirst">…</p>
  </a>
</div>

Links and button

One link style closes a section, one micro style jumps within a page, one button per page.

How an engagement works → What I do ↓
Start a conversation → 
<a class="link-arrow" href="…">… <span class="link-arrow__arrow" aria-hidden="true">&rarr;</span></a>
<a class="jump-link label" href="#…">… <span class="link-arrow__arrow" aria-hidden="true">&darr;</span></a>
<a class="btn" href="…"><span class="dot"></span>… <span class="btn__arrow">&rarr;</span></a>

Credential

Takes its type from the context it sits in. Micro label in the fold, footer meta below.

CE Cyber Essentials certified 
<span class="credential label">
  <span class="credential__mark" aria-hidden="true">CE</span>
  <span>Cyber Essentials certified</span>
</span>

Datum marker

Hangs on a stratum boundary at the content rail. Its parent needs position:relative, which .stratum already has. Use it once or twice per page. Two markers close together read as a fault.

<span class="datum" aria-hidden="true">
  <svg viewBox="0 0 24 24"><path d="M4 7.6 H20"/><path d="M12 8.4 L5.2 19"/>
  <path d="M12 8.4 L18.8 19"/><path d="M12 8.4 V19"/></svg>
</span>

<!-- on a bedrock boundary -->  <span class="datum datum--sunken">…</span>

Strata

Sections are bands of the core sample. Alternate --pale and --warm down a page and close on --bedrock. Reversed type is handled for you inside the bedrock stratum.

<section class="stratum stratum--pale">
  <div class="wrap stratum__inner duo">…</div>   <!-- two columns -->
</section>

<section class="stratum stratum--warm">
  <div class="wrap stratum__inner">…</div>       <!-- one column -->
</section>

Article prose

Extensions to .prose for long-form Markdown bodies (css/components/article.css). Jekyll renders a post's Markdown inside a .prose wrapper in the article layout, so headings, lists, links, quotes and code need no classes. Headings are the sans at 600 — the serif appears once per article, as the title in the page head. Links underline in the hairline colour and darken to ink on hover; the accent stays out of text.

A body heading

Running prose with an inline link and inline code.

  • An unordered list item
  • Another

A quotation against a hairline rule.

<div class="prose">
  <h2>…</h2>  <p>…</p>  <ul>…</ul>  <blockquote>…</blockquote>
</div>
<!-- In a post, just write Markdown; the article layout adds the wrapper. -->

Motion utilities

.u-enter runs on page load, staggered with --delay, and is used above the fold only. .u-reveal fades in on scroll, staggered with --i, and is used everywhere below it. Both are switched off under reduced motion, and .u-reveal content stays visible if JavaScript fails.

<p class="u-enter" style="--delay:.2s">…</p>
<div class="u-reveal" style="--i:1">…</div>
